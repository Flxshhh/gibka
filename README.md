# Листогиб — симулятор гибки листа

Веб-приложение без сервера и сборки для листогибочного пресса: каталог пуансонов и матриц с точными
контурами, конструктор детали, расчёт развёртки и анимация гибки с проверкой ударов.

**Открыть:** https://flxshhh.github.io/gibka/

Локально: открыть `index.html` в браузере (проверка новой версии работает только по http).

## Что умеет

- **Пуансоны и матрицы** — каталог (папки по углам, у матриц внутри по ширине ручья V), поиск, чертёж с размерами,
  3D-модель пуансона. «+ Копия» делает свою позицию в «Моих». Свой инструмент загружается из чертежа **DXF**.
- **Конструктор детали** — кнопками, строкой (`30 90 60 -90 30`), шаблоном или контуром из DXF; отмена и возврат,
  зеркальная деталь, развёртка и линии гиба.
- **Симуляция** — порядок гибов подбирается перебором с проверкой ударов о пуансон, матрицу и станок;
  матрица берётся по таблице усилий (среднее V для толщины). При ударе предлагаются другой пуансон, затем другая матрица.
  Вид 2D с приближением и 3D.
- **Карта гибки** для печати или PDF, **ссылка «только гибка»** для показа одной детали, **видео** гибки,
  **заявка** на инструмент.

Всё своё (инструмент, детали, станок) хранится в браузере; переносится через «Резервную копию».

## Файлы

| Файл | Назначение |
|---|---|
| `js/data.js` | таблица усилий, коэффициенты, станок и деталь по умолчанию |
| `js/catalog.js`, `js/catalog-dxf.js`, `js/catalog-dies.js` | каталог: параметрические пуансоны, пуансоны и матрицы с контурами из DXF |
| `js/geom.js` | геометрия листа, пуансонов, матриц, пересечения |
| `js/dxf.js` | чтение DXF в браузере: свой пуансон, своя матрица, контур детали |
| `js/calc.js` | подбор V, Ri, B, усилие, K-фактор, развёртка |
| `js/sim.js` | расстановка листа, столкновения, порядок гибов |
| `js/view3d.js` | 3D: модель пуансона и вид гибки (three.js грузится по требованию) |
| `js/ui.js` | интерфейс, плеер, печать, ссылка, заявка |
| `bump-version.sh` | перед выкладкой: обновляет номер версии в `index.html` и `version.txt` |

## Выкладка

```sh
./bump-version.sh && git commit -am "…" && git push origin main
```

GitHub Pages обновляет сайт за 1–2 минуты. Номер версии виден внизу страницы; открытый сайт сам предложит обновиться.

Требования к своим DXF: масштаб 1:1, миллиметры, профиль замкнутой линией; дуги — настоящими дугами.
