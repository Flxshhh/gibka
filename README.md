# Листогиб — симулятор гибки листа

Веб-приложение без сервера и сборки: расчёт развёртки, библиотека пуансонов и матриц
(чертёж и 3D), конструктор детали и анимация гибки с проверкой столкновений.

**Открыть:** https://flxshhh.github.io/gibka/

Локально: открыть `index.html` в браузере.

| Файл | Назначение |
|---|---|
| `js/data.js` | таблица усилий, коэффициенты, инструмент по умолчанию |
| `js/geom.js` | геометрия листа, пуансонов, матриц, пересечения |
| `js/calc.js` | подбор V, Ri, B, усилие, K-фактор, развёртка |
| `js/sim.js` | расстановка листа, столкновения, порядок гибов |
| `js/view3d.js` | 3D-модель пуансона (three.js) |
| `js/ui.js` | интерфейс и плеер анимации |
